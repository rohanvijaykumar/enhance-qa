# Accessibility
- Area: A11Y
- Paths: *
- Modules: accessibility

### A11Y-001 · Every form field has a label
- Risk: medium · Type: agent · Tags: a11y
- Steps: On /login, /signup, /reset, /cart (with an item), /checkout and /account, read each input's accessible name
- Expect: Every visible input has an accessible name
- Source: features/accessibility (WCAG 1.3.1, 4.1.2)

### A11Y-002 · Sign in works with the keyboard only
- Risk: medium · Type: agent · Tags: a11y
- Steps: On /login use Tab to reach Email, Password and "Sign in"; press Enter to submit with test user A
- Expect: Focus moves in a logical order and is visible; Enter signs in
- Source: features/accessibility (WCAG 2.1.1, 2.4.7)

### A11Y-003 · Pages declare a language
- Risk: low · Type: auto · Tags: a11y
- Command: `curl -s http://localhost:4310/ | grep -o '<html lang="[a-z-]*"'` → must match
- Expect: `<html lang="en">`
- Source: features/accessibility (WCAG 3.1.1)

### A11Y-004 · The shop works at phone width
- Risk: medium · Type: agent · Tags: a11y
- Steps: At 390×844, open /, a product, sign in, cart with an item, checkout
- Expect: No horizontal scrolling; all buttons reachable and readable
- Source: web-app: responsive

### A11Y-005 · The cart fits a phone screen
- Risk: high · Type: agent · Tags: regression
- Steps: At 390×844, cart with Ceramic mug (and with two items) → measure document.documentElement.scrollWidth
- Expect: scrollWidth ≤ 390; at 1280×800 the cart is still a normal table
- Source: BUG-018
