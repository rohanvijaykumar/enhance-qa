# Example output

`web-shop-qa/` is the real `qa/` folder enhance-qa wrote for the bug-zoo web shop (`tests/bug-zoo/web-shop/`) over two runs:
- run 001: setup, a full baseline and fixes;
- run 002: the next day's `check`.

Evidence (screenshots and logs) and local state are left out, as they would be in a project by default.

Start with [web-shop-qa/STATUS.md](web-shop-qa/STATUS.md), then open any bug in [web-shop-qa/bugs/](web-shop-qa/bugs/) or a run in [web-shop-qa/runs/](web-shop-qa/runs/).
