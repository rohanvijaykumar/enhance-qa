## What a user sees
Signing up with a name of only spaces works, and the account page greets them with "Hi" and nothing after it.

## Why it matters
Accounts end up with no usable name for greetings and orders.

## Steps
1. Open /signup
2. Name "   " (spaces only), a new @example.test email, a valid password
3. Press "Create account", then open /account

## Expected
Refused with a message asking for a name (source: forms-validation: required fields)

## Actual
302 to /account; heading "Hi" followed by blanks.

## Evidence
evidence/002/v1-c4t1.account.html · v1-c4t2.account.html · v1-c4t3.account.html

## Prompt for your coding agent
POST /signup in server.js doesn't require a non-blank name. Trim the name and refuse an empty one with a clear message (e.g. "Enter your name"). Add a test.
