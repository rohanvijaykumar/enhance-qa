## What a user sees
A new account can be created with a password of 8 spaces, and signing in with it works.

## Why it matters
A blank-looking password is trivially guessable and is almost certainly a mistake by the user.

## Steps
1. Open /signup
2. Name "R2V1 Test", a new @example.test email, password of 8 spaces
3. Press "Create account"

## Expected
Refused, like any password without 8 real characters (source: AUTH-006 rule "Password must be at least 8 characters"; forms-validation)

## Actual
302 to /account; the account exists and signs in.

## Evidence
evidence/002/v1-c3t1.html · v1-c3t2.html · v1-c3t3.html

## Prompt for your coding agent
POST /signup in server.js checks only `password.length >= 8`. Also refuse passwords that are only whitespace (e.g. `!password.trim()`), with the existing "Password must be at least 8 characters" message or a clear one. Add a test.
