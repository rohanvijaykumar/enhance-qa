## What a user sees
The script every browser downloads (/static/app.js) contains a Stripe secret key (sk_test_…).

## Why it matters
Anyone can copy a secret payment key from the page. Even a test key should never be public, and the same pattern with a live key would let others act on the payment account.

## Steps
1. curl http://localhost:4310/static/app.js

## Expected
No secret keys in files sent to the browser (source: SEC-005)

## Actual
`const STRIPE_SECRET_KEY = 'sk_test_…'` (value redacted) assigned into a client config object

## Evidence
Quoted output in qa/runs/001/verifier-2.md (C16, redacted)

## Prompt for your coding agent
static/app.js hard-codes a Stripe secret key (sk_test_…) in client code. Remove it from the client; secret keys belong only on the server, in an environment variable. Rotate the key in the Stripe dashboard if it was ever real. Add a check that served static files contain no sk_ keys.
