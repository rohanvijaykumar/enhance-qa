## What a user sees
Every product page throws a JavaScript error and the reviews area stays on "Loading reviews…".

## Why it matters
A visible stuck loading message on every product page, and a console error.

## Steps
1. As a guest open /product/1
2. Look at the console and the reviews area

## Expected
No script errors (source: SHOP-007)

## Actual
pageError: ReferenceError: reviewCache is not defined

## Evidence
evidence/001/shop-007.out.txt · evidence/001/v1-c1-out.txt

## Prompt for your coding agent
static/app.js loadReviews() reads reviewCache, which is never defined, so it throws on every product page. Guard it so no error is thrown and the reviews box doesn't stay on "Loading reviews…". Add a test if a client test setup exists.

## Fix notes
- Cause: loadReviews() in static/app.js read reviewCache, which is never defined, so it threw before replacing "Loading reviews…"
- Change: define an empty reviewCache (there is no reviews data source) and read (reviewCache[id] || []).length, so the box shows "0 reviews" using the existing "N reviews" text
- Files: static/app.js
- Test: no suite (no test framework in the project; none added). node --check server.js static/app.js passes. Bug steps run in headless Chrome against a fresh `PORT=4311 node server.js`, restarted between two runs: expected result both times (guest /product/1 and /product/2: box reads "0 reviews", no console error; the old app.js still logs "Uncaught ReferenceError: reviewCache is not defined" in the same harness)
- Halo: SHOP-007, SHOP-008, every page that loads app.js (only product pages have #reviews)
- Commit: b7edc45
