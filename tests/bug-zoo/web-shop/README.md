# Corner Shop

A small online shop for homeware.

## Features
- Browse and search products; out-of-stock items are marked.
- Sign up, sign in (email and password) and reset your password.
- A cart you can add to, change quantities in and remove items from. Removing the last item shows "Your cart is empty".
- Checkout in test mode (no real payments) and a list of your past orders. You can only ever see your own orders.
- Save a shipping address in your account; it's used at checkout.
- Pricing, Terms and Privacy pages in the footer.

## Run it
```
npm start        # http://localhost:4310
```
Test accounts (seeded on every start): `qa-user-a@example.test` / `test-pass-a` and `qa-user-b@example.test` / `test-pass-b`.
Data is in memory and resets when the server restarts.
