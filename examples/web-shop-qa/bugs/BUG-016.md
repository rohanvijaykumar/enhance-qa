## What a user sees
After searching for "mug", the results show but the search box is empty.

## Why it matters
Minor: users can't easily tweak their search.

## Steps
1. Search for "mug"

## Expected
The box still contains "mug" (source: SHOP-006, assumed convention)

## Actual
`<input name="q" value="">`

## Evidence
evidence/001/v2-c18.html

## Prompt for your coding agent
The search input on / always renders value="". Render the current query (HTML-escaped). Add a test.
