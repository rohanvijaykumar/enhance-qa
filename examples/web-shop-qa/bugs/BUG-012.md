## What a user sees
Posting the add-to-cart form for the out-of-stock Linen tea towel puts it in the cart and lets you check out.

## Why it matters
Orders for items the shop can't send. Needs a tampered or stale form, so fewer users hit it.

## Steps
1. Sign in
2. POST /cart/add productId=2 (Linen tea towel, stock 0)
3. Open /cart

## Expected
Not added (source: CART-008; README "out-of-stock items are marked")

## Actual
Linen tea towel $9.50 in the cart; total $9.50

## Evidence
evidence/001/cart-t2-curl.txt · evidence/001/v1-curl-out.txt

## Prompt for your coding agent
POST /cart/add doesn't check the product exists or is in stock. Refuse unknown products and products with stock 0 (redirect back without adding). Add a test.

## Fix notes
- Cause: POST /cart/add added any productId without checking the product exists or has stock (server.js, POST /cart/add)
- Change: look the product up first: unknown id redirects to / and stock 0 redirects back to /product/<id>, both without adding (one check fixes BUG-012 and BUG-013)
- Files: server.js
- Test: no suite (no test framework in the project; none added). node --check server.js static/app.js passes. Bug steps run against a fresh `PORT=4311 node server.js`, restarted between two runs: expected result both times (productId=2 redirects to /product/2, cart and checkout stay empty; in-stock add still works)
- Halo: CART-001, CART-002, CART-008, CART-012, SHOP-002, CHK-001. Same commit as BUG-013
- Commit: 610288c (also covers BUG-013)
